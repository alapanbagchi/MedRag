# WRITING STYLE - STRUCTURED REVIEW

Shape:
1. DEFINITION / SCOPE: define the topic and state the review's scope in
   one short opening section (what was asked, what the evidence covers).
2. EVIDENCE BY THEME: the body - one section per theme of the question,
   each with its verified evidence and inline [Pn] citations. Order
   themes by importance to the question, not by shore.
3. COMPARISONS & CONFLICTS: where sources disagree or report different
   magnitudes, present both sides with their [Pn]s and say how the
   evidence weighs them (do not silently pick).
4. UNCERTAINTY: study-design limits, ranges, and confidence, as the
   passages state them.
5. GAPS: what the evidence does not establish (the UNCOVERED list).

Rules:
- Systematic tone: cover every theme, integrate passages (do not dump
  quotes), prefer specific evidence over broad claims.
- Use sub-headings per theme when 3+ themes exist.
- Never resolve a conflict the evidence does not resolve; present it.
- Presentation: one `##` per theme; a comparison table when the evidence
  weighs 3+ options or sources on shared attributes; keep each theme to a
  few paragraphs; put limits and gaps in their own final sections.
- End with the `## References` list from the base skill.

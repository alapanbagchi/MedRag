# WRITING STYLE - CONCISE CLINICAL (default)

Shape:
1. OPENING: the direct answer in 1-3 sentences, with the key [Pn]
   citation(s) inline. The reader must get the answer before any detail.
2. SECTIONS: one section per part of the question, in the order the
   question raised them. Each section: short topic-sentence lead, the
   evidence, and the bottom line. Use headings only when 2+ sections.
3. GAPS: a short final section "What the evidence does not establish",
   listing each UNCOVERED requirement plainly.

Rules:
- Prefer the shortest complete answer. Cut background the question did
  not ask for; no general pathophysiology lessons.
- Give numbers when the passages have them (magnitude, ranges, CIs).
- Keep every section to a few sentences unless the evidence demands more.
- Presentation: no heading for a one-part answer; `##` headings when
  there are 2+ parts; a short bullet list for parallel options or steps;
  a table only when comparing 3+ options.
- End with the `## References` list from the base skill.

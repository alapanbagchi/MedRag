V2.3: JATS XML -> Markdown -> PageIndex pipeline + XML-tree builder

- jats_convert: batch command using the installed jats package
  (parse_jats_xml + convert_to_markdown) to convert the ORIGINAL ARTICLE XML
  into Markdown saved in index/pageindex_md/{paper_id}.md; keeps real XML
  section titles, inline table/figure positions, re-adds floats-group content
  (figures at first in-text citation, tables in XML floats order), and
  normalizes bold table/figure labels into #### headings for md_to_tree
- pageindex_build --from-md: builds PageIndex artifacts from the Markdown via
  the official pageindex.page_index_md.md_to_tree, with exact-text chunk
  re-attachment for paragraphs and honest md-unmapped reporting for tables
- xml_tree: XML structural parser producing the semantic document tree
  (document/section/subsection/paragraph/table(+summary+header+rows+footnotes)/
  figure(+caption)/list(+items)/references) with tables/figures at source
  locations, deterministic chunk-id mapping (tables by XML id, text-matched
  prose with merge detection, exact-text fallback), breadcrumbs, registries
  (section/table/figure/chunk_to_node/node_to_parent/node_to_children),
  14-check validation (PMC11092466 and PMC11743609 both PASS), old-vs-new
  comparison support, and part-28 debug reports
- acceptance tests made artifact-mode agnostic

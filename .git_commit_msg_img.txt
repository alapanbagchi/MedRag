jats_convert: correctly parse media and resolve image/graphic hrefs

- media/graphic hrefs are read from both xlink:href and href on
  <graphic>/<inline-graphic>/<media>/<video>/<audio>
- figure images and image-type media (mimetype/mime-subtype or extension)
  render as ![label](url); other media render as Media: [file](url)
- relative hrefs resolve to the absolute PMC OA URL using the corpus parser's
  convention (https://pmc-oa-opendata.s3.amazonaws.com/{pmcid-ver}/{href}),
  so the Markdown images/links actually load; --image-base-url to override,
  --no-resolve-media to keep relative paths
- media parsing applied in the sm supplement, floats-group figures, and a
  post-pass over the whole Markdown (image links + Media lines)
- fixed over-escaped metadata regex (n_images) that broke conversion
- verified: PMC10327125 (9 figs + 9 data files), PMC11684812 (5 figs + 9
  source files with captions), PMC11092466 (2 figs + media-1.docx),
  PMC11743609 (5 figs); 0 relative hrefs left; tests pass
